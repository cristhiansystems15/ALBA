# Módulos de ALBA

Cada módulo funcional tendrá su propia carpeta para mantener el proyecto organizado y escalable.

- `inicio/` — experiencia principal
- `noticias/` — actualidad
- `datos/` — indicadores y visualizaciones
- `tendencias/` — patrones y temas emergentes
- `investigaciones/` — investigaciones y análisis profundos
